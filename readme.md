# E-commerce Product System

## Description
This project fetches product data from an API and displays product details and discounted prices using TypeScript.

## Features
- Fetch products from an API.
- Display product details.
- Calculate discounted prices.
- Handle network and product errors.

## Technologies
- TypeScript
- Node.js
- DummyJSON API

## How to Run
npx tsc
node dist/main.js
