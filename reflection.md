## E-commerce Product System

A TypeScript project that fetches product information from an API.

## Reflection
- I used TypeScript and OOP concepts to create a Product class and methods to display product details and calculate discounts and taxes.
- One challenge was understanding how API requests work and how to test errors. I tried different URLs to check how my error handling worked.
- I used async/await to fetch products and try/catch to handle errors. I also created a custom error class to show an appropriate message when an API request fails.
